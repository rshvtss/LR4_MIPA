# AI-підкріплений дата-аналітик (Analytical AI Assistant)

Прототип AI-асистента для продуктової та бізнес-аналітики, побудований на базі **Python (Pandas, Matplotlib)** та **Google Gemini API** у середовищі Google Colab. Інструмент автоматизує рутинні етапи роботи з даними: первинний аудит якості (EDA), генерацію продуктових гіпотез, виконання ad-hoc запитів природною мовою, побудову візуалізацій та формування управлінських звітів (Executive Summary).

Архітектура рішення розділяє відповідальність між детермінованим кодом та мовною моделлю: **усі математичні та статистичні розрахунки виконує Pandas**, а LLM отримує вже агреговані метрики або схему таблиці у форматі JSON для інтерпретації та генерації коду без галюцинацій чисел.

## Реалізовані функції

1. **`auto_eda(df)`** – програмно збирає статистичний профіль датасету (типи колонок, явні `NaN` та приховані пропуски у вигляді пробілів, дублікати, викиди за IQR) і генерує текстовий аудит якості даних та рекомендації з очистки.
2. **`suggest_hypotheses(df, target_col)`** – розраховує базовий рівень відтоку (`Churn`) та сегментовані метрики (`groupby`), після чого формулює 7–8 обґрунтованих продуктових гіпотез із посиланням на точні цифри з датасету.
3. **`ask_data(df, query)`** – перетворює питання природною мовою на виконуваний Pandas-код з урахуванням схеми таблиці та унікальних значень категорій, виводить код для перевірки логіки аналітиком і повертає результат. Відхиляє нерелевантні або нелогічні запити.
4. **`generate_executive_summary(df, hypotheses_data)`** – обчислює фінансові втрати від відтоку (Monthly Revenue at Risk) та формує стислий бізнес-орієнтований звіт для керівництва із пріоритетними кроками.
5. **`visualize_data(df, query)`** – генерує Python-код на базі `matplotlib` за текстовим запитом, виводить код на екран та будує відповідний графік.

## Технології та бібліотеки
* **Python 3.10+** / **Google Colab**
* **Pandas**, **NumPy** – очистка даних, агрегація, статистичні розрахунки та виконання згенерованого коду в ізольованому середовищі.
* **Matplotlib** – побудова графіків за природними запитами.
* **Google GenAI SDK (`google-genai`)** – взаємодія з моделями сімейства Gemini (`gemini-3.5-flash-lite` з резервуванням на `gemini-2.5-flash-lite`) у режимі структурованого виводу (`application/json`).

## Інструкція із запуску в Google Colab
1. Отримайте безкоштовний API-ключ у [Google AI Studio](https://aistudio.google.com/) (розділ **Get API key -> Create API key**).
2. Відкрийте ноутбук `lab4_analytics_assistant.ipynb` у Google Colab.
3. У лівій панелі Colab відкрийте вкладку **Secrets** (іконка ключа), натисніть **+ Add new secret**, створіть змінну з назвою **`GEMINI_API_KEY`**, вставте скопійований ключ та увімкніть перемикач **Notebook access**.
4. Переконайтеся, що у змінній `CSV_URL` вказано актуальне `raw`-посилання на файл `WA_Fn-UseC_-Telco-Customer-Churn.csv`.
5. Запустіть усі комірки ноутбука (**Runtime -> Run all**).
